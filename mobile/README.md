# 📱 Avisa Aí Professor - Mobile

Aplicativo mobile desenvolvido com **React Native + Expo** para consumir a API do projeto **Avisa Aí Professor**.

## 🚀 Stack

- Expo SDK 57
- React Native
- TypeScript
- Expo Router
- TanStack React Query
- Axios
- React Hook Form
- Zod
- Expo Secure Store
- Expo Notifications

## 📂 Estrutura

```
app/
src/
  ├── components/
  ├── config/
  ├── constants/
  ├── contexts/
  ├── hooks/
  ├── lib/
  ├── providers/
  ├── services/
  ├── storage/
  ├── theme/
  ├── types/
  ├── utils/
  └── validations/
```

## ▶️ Executando

```bash
npm install
npm start
```
