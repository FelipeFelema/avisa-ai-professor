The latter is a transitive major change: Prisma's consumed named `deepmerge` export remains available, Node 22 satisfies its engine, and actual Prisma config/schema/generation/migration and backend regression gates verify the controlled repository configuration. No Prisma schema, migration, Nest major or Prisma major changes.
- Mobile retains Expo 57, React Native 0.86.3 and React 19.2.3: raise Axios's minimum to `^1.20.0`, resolve brace-expansion 1.1.21 / 5.0.12 and xmldom 0.8.15 / 0.9.12 within their consumers' existing ranges. Both lockfiles are synchronized. No `npm audit fix --force`, stack downgrade, vendored fork or advisory suppression.
