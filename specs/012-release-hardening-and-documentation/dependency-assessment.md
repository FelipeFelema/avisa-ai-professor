## Evidência e decisões para os sete pacotes destacados

- shell-quote: 1.9.0 → 1.12.0. Expo CLI usa quoting de comandos no computador de build. Injeção depende de texto controlado entregue ao shell; atualização compatível aplica fix sem alterar SDK.
- decode-uri-component: Expo Router → query-string 7.1.3 → decoder. DoS foi reproduzido no caminho real de parse; [decisão aprovada e retestes](evidence/decode-remediation-decision.md). Patch local mantém CommonJS e plus-to-space, usa algoritmo iterativo oficial. npm ci PASS e checker separado PASS; não é apenas supressão do audit. Inclusão/ligação do patch e factory minificada no export auditado confirmadas.
- braces: micromatch → braces, em Jest/Metro/webpack/ts-loader. Recursão com glob adversarial; nenhum endpoint backend chama essas ferramentas. Repo/asset glob são entrada de build. Sem fix publicado; não inserir override fictício. Backend omit=dev zero. Inventário source maps Android confirmou ausência desta instância.
- image-size: Expo/Metro asset tooling → image-size 1.2.1. Parse adversarial de JXL/HEIF/ICNS pode travar o processo de build. App não recebe upload de imagens para essa ferramenta; assets locais controlados são o vetor observado. Fix 2.0.3 altera major, não aplicado. Ausência comprovada neste export JS; não extrapolar para APK/AAB futuro.
- node-forge: Expo CLI/code-signing certificados → node-forge 1.4.0. Forgery depende da validação RSA vulnerável de assinatura/certificado; não substitui JWT backend. Sem fix publicado. Não foi testada a aceitação de uma assinatura forjada pelo EAS/Expo; ferramentas de build continuam vulneráveis no contexto descrito, sem aceite de risco implícito.
- sprintf-js: js-yaml 3.x → argparse → sprintf-js 1.0.3. Precisão/tamanho de formato adversarial pode causar DoS; parsing YAML/CLI identificado em tooling, não em endpoint de negócio. Sem versão corrigida publicada; instalar latest 1.1.3 não remediaria o advisory.
- uuid: Expo config plugins → xcode → uuid 7.0.3. Funções v3/v5/v6 com parâmetros de buffer/offset adversariais; xcode controla geração de IDs de projeto no build. Fix 11.1.1 exige major e análise do parent; não aplicado. Não concluir que toda função uuid é vulnerável nem que o app usa essa instância em runtime.
